# World Transit AI (Forge 1.21.1) — Концепт-ядро и исходный проект мода

Этот архив содержит готовую структуру проекта и исходный код на **Java 21 под Minecraft Forge 1.21.1**, который объединяет твои идеи в единую архитектуру:

1. **ИИ-генератор реального метро и железных дорог (`MetroAIGenerator.java`)**:
   - Подключается к гео-базе **OpenStreetMap (Overpass API)** и встроенным пресетам (**Санкт-Петербург**, **Токио**, **Париж** и любые другие города мира).
   - Переводит реальные географические координаты станций в блоки Minecraft и автоматически строит под землёй (или на эстакадах) детальные станции с колоннами, сводами, освещением и тоннелями.
2. **Оптимизированные микроблоки и мебель для слабых ПК (`OptimizedVoxelMeshCache.java`)**:
   - Реализует идею **Bits & Chisels + Furniture Builder** через алгоритм **Greedy Meshing** (склеивание полигонов) и **3 уровня LOD (Level of Detail)**. Вблизи детализация максимальная (16×16×16 внутри блока), а на расстоянии мелкие полигоны автоматически упрощаются, чтобы не просаживать FPS на слабых компьютерах.
3. **Мультимодальный транспорт и телеметрия (`MultiModalTransitVehicle.java`)**:
   - Единый физический класс для поездов метро, высокоскоростных поездов (Сапсан, Синкансэн, TGV), фуникулёров, самолётов и кораблей.
   - Включает расчёт телеметрии в стиле **Train Main** (графики скорости, тяги, тормозного пути и напряжения контактной сети).

## Как протестировать команду генерации в игре после сборки:
Введи в чате Minecraft:
- `/transitai build metro Санкт-Петербург` — построит ветку Петербургского метро (Площадь Восстания -> Владимирская -> Пушкинская -> Технологический институт -> Балтийская -> Автово) с колонными залами!
- `/transitai build railway Tokyo` — построит японскую линию Синкансэн / Яманотэ.
- `/transitai build metro Paris` — построит линию Парижского метро и вокзалы TGV.
- `/transitai build metro <Любой город мира на английском>` — сделает живой запрос в сеть через Overpass API и построит станции выбранного города.

## Как собрать готовый `.jar` файл на своём ПК за 3 шага:
1. Скачай и открой бесплатную программу **IntelliJ IDEA Community Edition** (с установленной Java 21).
2. Распакуй этот архив и открой папку проекта в IntelliJ IDEA (она автоматически скачает Forge 1.21.1).
3. В правой панели **Gradle** нажми `Tasks -> build -> build` — готовый файл мода появится в папке `build/libs/worldtransitai-forge-1.21.1-1.0.0-alpha.jar`.
